About the application / Về ứng dụng

automation thread (Meta app ID 1109750755284751) is a development-stage Threads API integration maintained by mvtruong2008-jpg.

With appropriate Meta authorization, it reads permitted Threads keyword-search results, identifies possible topics and uses Gemini to create original Vietnamese-language text drafts only. It does not currently publish Threads posts, interact with other accounts, or promise any engagement ranking.

Ứng dụng đang phát triển. Khi được Meta cấp quyền phù hợp, công cụ tìm các bài công khai theo từ khóa, lọc chủ đề và tạo bản nháp tiếng Việt bằng Gemini. Công cụ không tự đăng bài công khai.

Privacy and control: Authorized access tokens are stored in GitHub Actions Secrets. Research artifacts can be visible in the public source repository and currently have a three-day retention setting. Users can withdraw their Threads authorization.
